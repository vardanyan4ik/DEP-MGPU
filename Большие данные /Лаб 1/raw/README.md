# Логи команд (`raw/`)

В эту папку я сохраняю текстовые доказательства выполнения лабораторной.

## Быстрый способ
Запускаю:

```bash
./commands_for_screens.sh
```

После запуска автоматически формируются:
- `01_start_services.txt`
- `02_jps_processes.txt`
- `04_hdfs_put_ls.txt`
- `05_08_pyspark_run.txt`
- `05_schema.txt`
- `06_null_checks.txt`
- `07_peak_months.txt`
- `08_sql_seasonal_coeff.txt`
- `09_plot_file.txt`
- `10_hdfs_output_files.txt`
- `11_stop_services.txt`

Эти файлы использую как основу для скриншотов и как подтверждение выполнения шагов.
