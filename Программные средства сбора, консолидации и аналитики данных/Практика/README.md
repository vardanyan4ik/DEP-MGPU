## Индивидуальное задание: вариант 8

Проверялась гипотеза о наличии ценовой премии за высокий рейтинг. Для этого построена диаграмма рассеяния «рейтинг — цена» с линией тренда и рассчитаны медианные цены для каждого рейтинга.

Полученные результаты:

| Рейтинг | Количество книг | Медианная цена, £ |
|---:|---:|---:|
| 1 | 11 | 31.30 |
| 2 | 4 | 33.63 |
| 3 | 11 | 39.24 |
| 4 | 5 | 34.74 |
| 5 | 4 | 29.90 |

Коэффициент корреляции рейтинга и цены равен **−0,053**, наклон линии тренда — около **−0,55 £ за одну звезду**. В собранной выборке устойчивой ценовой премии за высокий рейтинг не обнаружено. Наиболее высокая медианная цена наблюдается у книг с рейтингом 3, а у книг с рейтингом 5 она ниже. Это означает, что рейтинг сам по себе недостаточен для объяснения цены; для практического анализа следует дополнительно учитывать жанр, автора, формат и издателя.
