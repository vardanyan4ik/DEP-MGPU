## Описание

Работа посвящена сбору данных с динамических страниц, содержимое которых формируется JavaScript. В тетради реализованы два независимых способа автоматизации браузера: Playwright и Selenium. Оба парсера ожидают появления таблицы, выполняют действия на странице, извлекают строки и проверяют совпадение результатов.

Для воспроизводимого выполнения используется локальный учебный стенд `market_stand.html`. Профиль `metals` формирует набор из 30 инструментов рынка металлов. Отдельно рассмотрены правовые и технические ограничения сбора данных с реальных источников.

## Индивидуальное задание: вариант 8

Тема варианта — драгоценные металлы как инструмент хеджирования. На учебном стенде проанализированы 30 инструментов профиля `metals`.

Основные результаты контрольного запуска:

- лидер по объёму — **Ni**, объём **3 884 726 147**;
- доля трёх крупнейших инструментов в общем объёме — **25,64%**;
- медианное изменение цены — **−0,83%**;
- максимальный рост — **Zn: +13,56%**;
- максимальное снижение — **Ag: −9,78%**;
- низкое отношение оборота к цене выявлено у **Ni, Pd и Ge**.

Распределение объёмов показывает умеренную концентрацию: три лидера формируют примерно четверть общего оборота. Одновременное присутствие положительных и отрицательных изменений подтверждает неоднородную динамику инструментов. При использовании металлов для хеджирования следует учитывать ликвидность конкретного инструмента, ценовой спред и структуру портфеля, а не ориентироваться только на изменение цены за один период.
