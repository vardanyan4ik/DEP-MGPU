# Программные средства сбора, консолидации и аналитики данных

Учебные работы по сбору и анализу данных, выполненные для варианта 30.

## Содержание

### Лабораторная работа № 1

Современный парсинг динамических веб-сайтов с помощью Playwright и Selenium.

- сбор данных с динамической витрины;
- XPath-селекторы и стратегии ожидания;
- преобразование цен, процентов и значений с суффиксами K/M/B;
- аналитика капитализации, оборота и суточного изменения активов;
- учебный локальный стенд `market_stand.html` и его изображение `page.png`.

Ноутбук: `Лабораторная работа/lr1_dynamic_variant_30_completed.ipynb`.

### Практическая работа № 1

Работа с открытыми API, статическим HTML и регулярными выражениями.

- получение открытых данных через REST API;
- парсинг с BeautifulSoup и XPath;
- очистка и консолидация данных в pandas;
- анализ ассортимента, цен и рынка труда;
- визуализация результатов.

Ноутбук: `Практика/pw_01_variant_30_completed.ipynb`.

## Запуск

Ноутбуки рассчитаны прежде всего на Google Colab, но могут запускаться локально в Jupyter Notebook.

1. Установите Python 3.10 или новее.
2. Создайте виртуальное окружение.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Откройте нужный `.ipynb` в Jupyter Notebook или VS Code.
5. Выполняйте ячейки по порядку сверху вниз.

Для лабораторной работы основной сценарий использует Playwright. После установки пакетов может потребоваться команда `playwright install chromium`.

## Безопасность

Ключи и токены в репозитории не хранятся. Если выбранный источник требует авторизацию, ноутбук получает секрет из Google Colab Secrets, переменной окружения или безопасного интерактивного ввода.
