В репозитории собраны две выполненные работы по получению, очистке, объединению и анализу данных из интернет-источников.

## Состав репозитория

### [Практическая работа 1](Практика/README.md)

Открытые API, HTML-парсинг и регулярные выражения. Через GitHub API получены 100 репозиториев, с Books to Scrape собраны карточки книг категории Romance. В индивидуальном задании проверена зависимость цены книги от рейтинга.

Основной файл: [`pw_01_variant_8_completed.ipynb`](Практика/pw_01_variant_8_completed.ipynb).

### [Лабораторная работа 1](Лабораторная%20работа/README.md)

Динамический парсинг с Playwright и Selenium. Оба браузерных движка извлекают данные профиля `metals` с локального JavaScript-стенда. Выполнен анализ динамики, объёмов и концентрации рынка.

Основной файл: [`lr1_dynamic_variant_8_completed.ipynb`](Лабораторная%20работа/lr1_dynamic_variant_8_completed.ipynb).

## Быстрый запуск

1. Откройте нужную тетрадь в Google Colab.
2. Для лабораторной работы загрузите рядом файл `market_stand.html`.
3. Выполните **Runtime → Run all**.

Зависимости перечислены в [`requirements.txt`](requirements.txt). В репозитории нет API-ключей, токенов и конфиденциальных материалов.
