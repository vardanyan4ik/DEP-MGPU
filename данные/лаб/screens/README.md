# Скриншоты для отчета (вариант 9)

Сохраняйте скриншоты именно с такими именами, чтобы они автоматически подтянулись в `Report.md`.

1. `01_start_services.png` — запуск `start-dfs.sh` и `start-yarn.sh`.
2. `02_jps_processes.png` — результат `jps`.
3. `03_namenode_ui.png` — web UI NameNode (`localhost:9870`).
4. `04_hdfs_put_ls.png` — команды `hdfs dfs -put` и `hdfs dfs -ls`.
5. `05_schema.png` — вывод `printSchema()`.
6. `06_null_checks.png` — вывод проверки пропусков до/после очистки.
7. `07_peak_months.png` — таблица `peak_months.show()`.
8. `08_sql_seasonal_coeff.png` — таблица `seasonal_coeff.show()`.
9. `09_seasonality_plot.png` — итоговый график сезонности.
10. `10_hdfs_output_files.png` — список файлов результата в `/user/hadoop/lab_01/output`.
11. `11_stop_services.png` — остановка `stop-yarn.sh`, `stop-dfs.sh`.

Рекомендуемый формат: PNG, ширина 1400-1920 px.
